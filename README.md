Project plan

 Project idea
A cute, aesthetic, interactive web-based To-Do List application.

Planned features

- Dynamic Task Creation & Management: Add new tasks, mark them as completed AND delete them dynamically.
- Visual Progress Tracking: Real-time progress bar and task counter (e.g., `0 / 0`) that updates automatically as tasks are created or completed.
- Date box A real-time calendar box displaying the current day, day number, month, and year.
- Local Storage Persistence: Saves tasks locally in the browser so they persist upon page refresh.
- Input Validation & Error Handling: Prevents empty task submissions and displays helpful inline feedback messages.

Technologies
- HTML5: Core semantic markup, input elements, structural containers, and accessibility attributes.
- CSS3: Custom styling, Flexbox layout management, keyframe animations (`@keyframes`), relative/absolute positioning, and Google Fonts (`Jua`).
- JavaScript: DOM scripting, event listeners, dynamic element rendering, form validation, and state management.
- Font Awesome: Scalable icons for action buttons (checkmarks, edit, delete).
- localStorage: Saving task data as JSON strings in the client's web browser for state persistence across browser sessions.


How to use the application
1. Open the published application using the GitHub Pages link provided above.
2. View the automatically populated date widget in the top-left corner.
3. Type a task name into the "Add a new task..." input field and click the **`+`** button or press **Enter**.
4. Click the circular checkmark icon to mark a task as completed (or unmark it).
5. Observe the progress bar and counter updating in real time as tasks are modified.
6. Refresh or reopen the page to confirm that saved tasks persist in the browser via `localStorage`.
